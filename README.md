# Sistema de Vuelos Baratos

## Descripción

Este proyecto consiste en el desarrollo de un sistema de consola para el encuentro de vuelos baratos a partir de una base de datos ficticia.

La aplicación fue desarrollada en C# utilizando Visual Studio Code y una estructura de datos basada en listas para almacenar y procesar la información de los vuelos.

## Funcionalidades

- Cargar vuelos desde un archivo de texto.
- Mostrar todos los vuelos disponibles.
- Buscar vuelos por origen y destino.
- Identificar el vuelo más barato.
- Buscar vuelos por aerolínea.
- Generar un reporte de los vuelos.
- Comparar precios.
- Validar información ingresada por el usuario.

## Estructura del proyecto

- Program.cs: contiene la lógica principal y el menú del sistema.
- Vuelo.cs: contiene la clase que representa cada vuelo.
- vuelos.txt: contiene los registros ficticios de vuelos.
- README.md: contiene la documentación básica del proyecto.

## Datos utilizados

Los vuelos utilizados en el sistema corresponden a información ficticia almacenada en un archivo de texto.
